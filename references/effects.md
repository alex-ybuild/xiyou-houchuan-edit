# 通用动作特效与调色

用户接受法术感或要求特效时读。目标是给已有动作增加力量感，剪辑结构仍以参考为准。本模块适用于人物、动物、运动物体、做饭和产品动作，不绑定猫、某一画幅或固定像素。

## 按事件选择，而不是全片套效果

| 素材事件 | 合适的效果 | 锚点与控制 |
|---|---|---|
| 出拳、挥爪、挥棒、球拍挥动 | 短拖影、局部光晕 | 挥动部位或运动主体；接触点可信才加闪光 |
| 跳跃、投掷、颠勺、物体飞行 | 沿轨迹残影、短光晕 | 运动方向；保留起点与落点，不制造不存在的碰撞 |
| 开盖、揭幕、产品展开 | 边缘柔光、揭晓瞬间局部亮光 | 产品边缘或开合点；不让光遮住细节、标志与文字 |
| 转头、表情、口播手势 | 很轻的推近或局部强调 | 表情或手部；不默认把讲话的人全身发光 |
| 风景、静态物品、低运动画面 | 克制调色、必要时轻柔光 | 通常不加拖影；不要强行制造事件 |

同一事件在三遍回放中复用相同效果相位，镜头切换时清空残影历史。倒放时轨迹与源时间映射一致。前半铺垫保持自然，主要出招组短暂进入法术感，结果镜头收回效果。

## 建议强度与时间单位

以下是创作起点，不是原剧统计；参考、素材与用户反馈优先。

- 拖影：取之前约 40–100 ms 的 1–3 个主体残像，逐层透明度约 0.08–0.22，沿实际运动轨迹摆放。根据 FPS 换算帧数；低帧率或原片已明显模糊时只留一层或跳过。不要拖影整幅背景和字幕。
- 光晕：跟随主体遮罩，优先边缘外发光，半径约画面短边 0.8%–2%，柔和淡入淡出约 80–160 ms。不要用固定像素描边，也不为所有素材默认加巨大光球。
- 色彩：单主体选一种与画面和叙事一致的强调色；双主体可用金／紫区分，保持身份映射稳定。多主体仅强调本镜头的主要动作，不轮流把每个人涂成不同颜色。
- 闪光：出招强调或可信的接触点持续约 40–80 ms，半径约短边 3%–8%，控制亮度与遮挡；与对应音效对齐。没有碰撞时不能把动作强调说成真实撞击。默认不用全屏白闪或连续闪烁。
- 调色：先修正曝光和白平衡，再小幅暖色、对比和亮部柔光。滤镜作用于视频素材，标题与字幕独立合成。保留肤色、宠物毛色和产品准确颜色；已有暖色、高反差或饱和素材降低或跳过调色。

清晰的全景可略强调边缘；低清、暗部噪点、运动模糊或大幅特写降低拖影和柔光强度，不叠加颗粒与额外模糊。日常、口播、产品镜头默认比武打素材更克制。用户说“轻一点”时先降低覆盖动作数量与透明度，不改变已校准的切点。

## 可执行的合成约定

每个事件记录 `subject_id`、输出区间、源时间映射、归一化锚点／轨迹、mask 来源、强调色、强度包络、拖影时间偏移、光晕短边比例与闪光时间。身份、事件选择和锚点必须来自当前素材分析，不能沿用上一个演示里的猫咪坐标。

遮罩优先用可用的主体分割／跟踪结果；简单轮廓可用人工多边形并逐镜检查。框或椭圆只适合软光氛围，不声称是精确轮廓。没有可信遮罩时跳过主体拖影与描边，保留局部动作强调和调色；不要把背景一起复制充当主体特效。

合成顺序：视频调色 → 按源相位准备主体和历史遮罩 → 动作效果 → 镜头裁切／缩放 → 视频与效果一起镜像 → 标题字幕。输出位置需对应每镜的裁切变换。不同素材的遮罩方法可以不同，但时间、归一化坐标和短边比例一致。

可用 [scripts/action_fx.py](../scripts/action_fx.py) 的 `mild_grade` 与 `action_fx` 做 Pillow/numpy 合成。该 helper 接受任意同尺寸的 RGB 帧与 L 遮罩；它不检测主体、不剪辑、不生成声音。调用方负责跟踪、切镜清空历史与效果时间线；不把它当成可自动识别任何视频的一键工具。

强描边前先检查遮罩：背景家具、地面阴影和相近颜色不能跟着发光。运动模糊素材可结合当前素材的前景分割、跟踪边界与背景排除；颜色阈值或多边形只是初始化，不能把明显的几何边界当成主体轮廓。遮罩不可信时退回软光、光束或光圈，避免强化错误轮廓。

浅色小物体与桌面、墙面相近时，全幅分割可能只保留初始化种子的一小块。可以在跟踪到的物体局部区域内分割，并检查抬起、近景和放下三个相位；轮廓应贴住真实物体边缘，不应变成种子方框。人物和持物可以分别使用遮罩与强调色，不能因人物轮廓清楚就默认物体遮罩也正确。

验证至少观察一次全景、近景、镜像回放和事件结束：主体轮廓不漂移，字幕不带拖影，镜像后的光效一致，光晕没有遮住脸或产品细节，音效与闪光同相位。需要展示效果变化时保留无特效版本做 A/B。

## 强法术档

用户明确要原剧那种浓烈描边、光束、闪电、分身或落地光圈时启用。保留已经校准的剪辑与音效时间线，强度档只改变视觉合成。轻法术和强法术分别保存，避免只把轻版滤镜加重就声称做了强特效。

- 强描边：主体遮罩生成清楚的金／紫外轮廓与亮芯，叠加较宽的柔光。轮廓宽约短边 0.5%–1.2%，外光约 1.5%–3%；80–150 ms 进入，出招后约 150–300 ms 收回。脸部、手部、产品细节留出可读度，近景缩窄轮廓并减少覆盖。
- 法术光束／闪电：以当前出招部位为发射点，沿动作方向或明确的虚构法术目标延伸，持续约 80–200 ms。使用归一化起终点、亮芯与外发光；只在出招组出现，不把整段画面铺成电网。纯法术改编允许虚构光束，但说明它是视觉改编，不能把虚构命中或伤害描述为源片中的真实事件。
- 分身残影：使用约 60–180 ms 前的 2–3 个主体姿态，逐层透明度约 0.12–0.30，必要时染为同一主体的强调色。保持轨迹和轮廓；原本模糊的特写可以只用描边，省略分身。
- 落点光圈与轻烟：只在可信的落点或明确的法术锚点触发。光圈在约 250–500 ms 内向外扩展并淡出，半径约短边 5%–25%；地面圆环可压成椭圆。烟团在约 200–500 ms 内扩散，不能长期遮住结果。

单次事件选 1–2 个主要效果，并非把所有效果叠在每个动作上。人物／动物武打可用明显轮廓与分身；球类和飞行物强调物体轨迹；产品默认突出边缘与揭晓点，减少烟雾和分身；口播与静态素材没有合适事件时不强行套强档。

[scripts/action_fx.py](../scripts/action_fx.py) 的 `strong_spell_fx` 提供强描边、归一化光束、地面环和轻烟合成。所有触发时刻、遮罩、身份色彩与坐标由当前素材的事件时间线提供；helper 不自动判断碰撞、角色或法术目标。示例参数属于创作适配，不声称来自原剧工程。
