# 渲染与时间线规则

在实际剪辑时读此文件。目标是让风格设计可以稳定导出，不限定用户的软件。

## 建立可重现的事件时间线

源时间使用秒或帧，统一约定出点不包含在区间内。每个输出片段记录：

- `source`、`in`、`out`：源文件与区间。
- `event_id`：同一事件的回放共享标识，区分不同真实发生的动作。
- `direction`：forward 或 reverse。
- `crop`：可选的源像素裁切框；无裁切则为空。
- `speed`：默认 1；变速或速度曲线同时记录输出时长与源时间映射。
- `keyframes`：输出片段内的时间、scale、anchor_x/y、offset_x/y、easing；可选 freeze_frame、freeze_duration、shake 或 afterimage。
- `audio`：source、mute 或动作音效；对白保护优先。

例如拿杯动作源区间为 2.1–3.0 秒，三遍共享同一 event_id，分别使用全景、中景、手部景别；随后接源文件 3.0 秒之后的后续动作。倒放模式则使用相同区间的 forward、reverse、forward。这里的数字只用于说明时间线，不是通用动作检测参数。

源片段输出时长为 `(out - in) / speed`。总时长是所有输出片段时长之和，再考虑明确使用的转场重叠。根据这个值判断导出是否意外丢片或多出时长。

## FFmpeg 实现要点

先探测 `ffmpeg` 和 `ffprobe` 是否可用。缺失时检查用户指定编辑器或已有视频渲染工具；不要静默安装系统工具。无可用渲染路径时保留时间线并报告具体限制。

- 精确回放使用重新编码和解码后的 trim，而不是关键帧 stream copy。每个支路用 `trim=start=...:end=...`、`setpts=PTS-STARTPTS` 重置时间。
- 倒放只处理已经裁出的短动作片段，使用 `reverse` 后重置时间。不要对长源视频整体 reverse，它会缓存大量帧。
- 同一源流多次使用时用 `split` / `asplit` 或明确的独立输入，不能让多个消费者争用同一滤镜输出。
- 裁切先检查坐标、旋转后画幅和主体位置，再统一 scale/pad 到目标画布。拼接前统一尺寸、像素宽高比、帧率、像素格式、音频采样率和声道。
- 保留源音频的区间使用 `atrim` 和 `asetpts=PTS-STARTPTS`。没有音轨或回放需静音时补等长静音，避免 concat 音画段数不同。
- 对含重要对白的动作，第一次正常播放对白，重复段可用动作音效和 BGM；不能无意截断句子。BGM 作为独立连续音轨，在拼接画面后混入。
- 混音按输出时间轴放置冲击点，而非用源时间直接定位。控制峰值，抽听验证对白可懂度和音效强弱，不让多个重复音效叠成爆音。
- 变速视频使用对应的 PTS 调整；保留声音时同步调整音频速度，不要让音轨漂移。默认不用变速简化无必要的复杂度。
- 默认 MP4 / H.264 / yuv420p / AAC，并启用 faststart；目标尺寸使用偶数。保留用户的画幅和足够的细节。
- 调用程序用参数数组或正确的 shell 引用，避免文件名中的空格与特殊字符破坏命令。长滤镜图可以保存为文件。

可以按片段分别渲染后拼接，也可以建立整体 filter graph。前者更容易检查和重做，后者减少中间文件；根据素材规模选择。中间文件放在任务输出目录，最终成片不得覆盖输入。

## 验证

用 ffprobe 检查成片时长、音视频流、尺寸和帧率，结合时间线预期判断偏差；编码尾部少量帧级差异可以接受。使用 FFmpeg 完整解码检查损坏或时间戳错误，再实际播放代表性三连、折返、对白段及片头片尾。

只看缩略图不足以验证时间结构和声音。不能播放声音时，说明声音部分尚未听检；不能把解码通过等同于风格已经验证。

## 动态放大与关键帧

缩放围绕主体锚点计算源裁切框，每帧插值，并将裁切框限制在源画幅内。全景、中景、特写独立定镜头，动态推近是每个镜头内部的变化，两者不能互相替代。

FFmpeg 可用 zoompan 或分段滤镜；涉及多种关键帧、跟随锚点、定格和残影时，可解码为帧后用 Pillow 等现有图像库逐帧变换，再管道编码。逐帧渲染检查前后景别变化、主体不出框、缓动终点正确；优先浮点裁切或足够的内部渲染分辨率，避免低分辨率逐像素缩放造成抖动。

定格明确映射到一个源帧，重复的输出帧计入总时长。震动幅度短促且衰减，预留裁切余量，不能产生黑边。速度变化使用明确的源时间到输出时间映射，声音冲击点随该映射定位。
